# Lyra Playlist Generator

A full-stack web application that recommends songs based on users' preferred emotions, genres, and audio characteristics. Users customize their musical preferences through an interactive form and receive personalized recommendations generated by a custom scoring algorithm.

## How It's Made:

**Tech used:** Java, JSP, MySQL, JDBC

Lyra was built as a database-driven web application using Java, JSP, and MySQL. Users submit preferences such as mood, energy level, and genres through an interactive form. These preferences are processed by a custom recommendation algorithm that scores songs within the database based on how closely they match the selected criteria. We designed the application with a layered architecture using DAOs for database access and kept the recommendation logic separate from the presentation layer, making the system easier to maintain and expand.

## Optimizations

One of the biggest challenges was importing and processing a large music dataset without overwhelming the database, requiring the data to be parsed in manageable batches. Given more time, we would integrate external services such as the Spotify API, improve the recommendation algorithm, allow users to fine-tune additional filters like song length or excluded artists, and support features such as artist search, random playlist generation, and public hosting.

## Lessons Learned:

This project strengthened our understanding of full-stack application development, relational database design, and recommendation systems. We gained experience designing efficient database schemas, implementing DAO patterns, working with large datasets, and building algorithms that transform user input into meaningful recommendations. It also reinforced the importance of balancing ambitious feature ideas with realistic project scope and timelines while collaborating effectively as a development team.
